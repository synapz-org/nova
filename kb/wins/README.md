# Wins

Changes we tried that measurably improved an outcome. One file per win, named for the change.

**Required structure:**
- The change (what we did)
- The measurement (what changed, by how much, on what data)
- Where it lives in code (commit SHA, file path)
- When it might stop working (the assumptions baked in)

A claim without a measurement isn't a win — it's a hunch. If you can't quantify it, it doesn't belong here.
