# Losses

Changes we tried that didn't help (or hurt). One file per loss, named for the change.

**Required structure:**
- The change (what we did)
- The measurement (what we expected, what actually happened)
- Why we think it didn't work (best current theory)
- When it might be worth retrying (under what different conditions)

As valuable as `wins/` — saves the next person from running the same experiment.
