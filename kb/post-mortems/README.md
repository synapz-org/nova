# Post-mortems

When a session ends in significant lost work or a non-trivial outage, write the post-mortem here. Not for routine bug fixes (those go in `gotchas/` and `losses/`) — for events where the meta-question "how did we let this happen for so long" is more useful than the specific bug.

Format:
- Date in filename
- One-sentence root cause near the top
- Honest timeline
- Counterfactual: what should have been done differently
- Concrete what-would-prevent-this checklist at the end

Goal: the next person (or future-you) reads this and **doesn't repeat the same mistake.**
